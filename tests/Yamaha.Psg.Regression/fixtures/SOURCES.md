# Regression fixture provenance

Used only for local regression testing (comparison against a pinned baseline render), not for
distribution.

## `synthetic_melody_bass_drum.psg`
Generated by us for the end-to-end milestone-7 check: a channel-A arpeggio (2s) + a droning
channel-B bass through the envelope (shape 0x0A) + coarse per-frame "drum hit" pattern on
channel C (1s). Own code, no external sources — the generator lived in a scratchpad session and
is trivial to recreate if needed (see the session history where it was written).

## `user_provided/Pator - Detrimentum (2026) (Speccy.pl party 2026, 1).psg`
Provided by the user (a real compo track from the "Speccy.pl party 2026" AY music compo).
Author — Pator. Publicly available on zxart.ee (#598901, https://zxart.ee/tune/598901); the
demoscene traditionally distributes such tracks freely for listening/use in emulators. Used to
find and regression-test the envelope-restart-every-frame bug (see milestone 7 of the plan).

## `user_provided/Lyndon Sharp - Spike in Transylvania (1991).vtx`
Provided by the user. 1991 game music, author — Lyndon Sharp, VTX conversion by Ivan Yuskin.
Used for the end-to-end milestone-8 check (VTX/lh5) on a real file.

## `user_provided/Noro - Twilight - level 1 (1995).vtx`
Provided by the user. 1995 game music, author — Norbert Grellneth ("Noro"), VTX conversion by
Wixet. Used for the end-to-end milestone-8 check on a file with ACB panning (different from the
first VTX file, which uses ABC panning) — broadens coverage.

## Legal status
All three user-provided files are tracks from an open demoscene archive (zxart.ee), where authors
publish their own music for free listening/downloading. The files are used here only locally for
regression testing (not published or redistributed by this project).

**Resolution now that the repo is public**: `user_provided/` is gitignored — these binaries are
never committed, only the pinned SHA-256 baseline hashes in `FixtureRegressionTests` are.
`SpikeInTransylvania_MatchesApprovedRender`/`Twilight_MatchesApprovedRender`/
`Detrimentum_MatchesApprovedRender` skip gracefully (via a `File.Exists` guard) when the file isn't
present locally, so a fresh clone builds and tests green without them.
